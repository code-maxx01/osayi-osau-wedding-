# Wedding Website

A simple static wedding website demo with:

- guest input form for name, email, guest count, and message
- invitation preview and confirmation flow
- bride and groom information with photos
- gift suggestion section

## How to use

1. Open `C:\Users\hp\WeddingWebsite` in VS Code
2. Open `index.html` in your browser
3. Fill out the form and review the invitation
4. Click "Send Invitation" to display the wedding details and gift options

## Customize

- Edit `index.html` for text and page layout
- Edit `styles.css` for colors and design
- Edit `script.js` for form handling and invitation behavior
